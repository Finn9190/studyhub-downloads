# StudyHub downloads

## Windows

[Download StudyHub for Windows](https://github.com/Finn9190/studyhub-downloads/releases/latest/download/StudyHub-setup.exe)

Install StudyHub, open it from the Start menu, and follow the first-run setup using your own h_da accounts. The first start needs internet to prepare the app. Git, Node.js and a separate Python installation are not needed.

## Mac (Apple Silicon, macOS 11 or newer)

[Download StudyHub for Mac](https://github.com/Finn9190/studyhub-downloads/releases/latest/download/StudyHub-mac.dmg)

Open the disk image and drag StudyHub into Applications. The app is not signed by Apple, so macOS blocks it the first time. To allow it once, open System Settings → Privacy & Security and click "Open Anyway" next to StudyHub. Then follow the same first-run setup; the first start needs internet. Intel Macs are not supported yet. The Mac app is new and has not been tested on many Macs: tell the maintainer if something does not work.

## Your data and updates

Each student keeps their own course files, settings, database and saved logins on their own computer. This repository distributes the Windows installer, the Mac disk image, the runtime update archive and the release manifest. It contains no student's notes, database, settings or credentials.

StudyHub checks for app updates automatically and waits for active work to finish before installing. Settings → Updates shows the current version and any Windows installer update.

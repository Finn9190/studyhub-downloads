# StudyHub downloads

[Download StudyHub for Windows](https://github.com/Finn9190/studyhub-downloads/releases/latest/download/StudyHub-setup.exe)

Install StudyHub, open it from the Start menu, and follow the first-run setup using your own h_da accounts. The first start needs internet to prepare the app. Git, Node.js and a separate Python installation are not needed.

Each student keeps their own course files, settings, database and saved logins on their own PC. This repository distributes the Windows installer, runtime update archive and release manifest. It contains no student's notes, database, settings or credentials.

StudyHub checks for app updates automatically and waits for active work to finish before installing. Settings → Updates shows the current version and any Windows installer update.
